# ADR-012 — Open-source license and repository boundary
**Status:** accepted (D-036) · **Date:** 2026-10-04
## Decision
Apache 2.0 for all open code (spec registry, SDKs, instrumentors, adapters, recorder, benchmark); CC-BY-4.0 for spec text and public corpus. Boundary per SPEC-08 §1. No source-available license for the open layer.
