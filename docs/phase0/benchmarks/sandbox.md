# Benchmark plan — replay sandbox (ADR-007)
Candidates: container + content-addressed filesystem snapshot (overlayfs upper layer or git tree); gVisor checkpoint/restore; Firecracker snapshot/fork (E2B-style); Modal snapshot restore. Workload: the Proof A session (11 model calls, 9 tool calls) and 50 SWE-bench-style sessions replayed at R2 and R3; 20 forks per step at 30% and 70% of trajectory. Measures: fork latency, restore latency, memory per fork, state-hash agreement, exit-code agreement, escape test results (network, filesystem, credentials), cost per replay. Pass: R3 agreement ≥ 99.9%, fork < 2 s for filesystem snapshots, zero escapes.
